## Plan Matrix: средняя цена (шаг 1, с 15.10.2026)

Google-таблица «Plan Matrix for Marketplaces» (ведёт аналитик, расшарена на наш SA `kabinet-external/google-sa-json`
редактором): вкладки маркетплейсов `Amazon_ES` … `TikTok_ES`, по три колонки на месяц — AVG Price, Units, Revenue.
Средняя цена — `Kabinet - Plan Matrix Prices` (`nb/plan_matrix_prices.py`, 16:30 Kyiv) → `kabinet_data.plan_price_daily`
(расчёт «на дату») и `plan_price_month` (цена месяца, `frozen`). Пороги и окна — `reorder_params.plan_price_*`.

- **В таблицу пишем только свои вкладки `avg_<вкладка маркетплейса>`** (`avg_Amazon_ES` … `avg_TikTok_ES`, формат
  согласован с аналитиком 14.10.2026) **и только при `plan_price_sheet_write = 1`**. Строки — на тех же номерах, что у неё
  (данные с 4-й), колонки — месяцы её шапки «October 2026» …, не меньше `plan_price_months_ahead` (15) вперёд. В ячейке
  только число: заморожен — серый фон, источник — цвет шрифта (легенда заметкой к A1). Перед записью — сравнение с прошлой
  записью (`plan_price_sheet_log`): цен меньше на `plan_price_sheet_guard_drop_pct` (30 %) или ноль — вкладку не трогаем,
  тревога `plan_price_sheet_guard`. Её вкладки, включая `prices_*`, не трогаем никогда.
- **Сервисный аккаунт не может создать файл в Google Drive** — квота у него нулевая («The user's Drive storage quota
  has been exceeded», 14.10.2026). Копию таблицы для пробы делает человек и открывает доступ SA редактором; ноутбук
  пишет в неё параметром `target_sheet`.
- **Заказы Amazon Vine — не продажа.** Промо `vine.enrollment…` списывает всю цену строки (единица бесплатно
  рецензенту), и без отсева «средняя цена» 84279000 ES выходила 8,99 € при цене 62,95 €. Отсеиваются Vine, заказы-замены
  и любые строки с ценой после промо ≤ 0. Тот же отсев нужен любому, кто считает цену из позиций заказов.
- **Расчёт «на дату» воспроизводим для продаж и снимков витрины, но не для офферов Mirakl**: `raw_lm/cf/mm_offers` —
  текущее состояние, истории нет. Месяц, замороженный задним числом (октябрь 2026 — «на 15.09»), получает текущую цену
  оффера с пометкой в `note`. Отсюда же: пропущенный прогон 15-го числа стоит дороже обычного.
- **Цена листинга Amazon — из SP-API, а не из скрейпинга** (решения владельца 14.10.2026). Источник — Listings Items
  (`searchListingsItems`, `attributes.purchasable_offer`): `our_price` и `discounted_price` (sale price) с датами
  действия, отдельно для всех покупателей (`audience = ALL`) и B2B. Ячейка 1 ноутбука кладёт его снимком дня в сырьё
  `dnipro_m.raw_amazon_listing_offers` (история — с 15.10.2026). Цена = меньшая из `our_price` и sale price, если та
  действует на дату расчёта; только BUYABLE и ALL. **Отчёт листингов (`raw_amazon_get_merchant_listings_all_data.price`)
  отдаёт только обычную цену, без sale price** — он остался запасом для дат без снимка Listings Items (заморозка октября
  на 15.09). У двух листингов (FBA и FBM) — меньшая цена. Из ScrapingDog берётся только купон (`coupon_text` в `raw`;
  флаг `has_coupon` без текста стоит у тысяч снимков без купона); нет листинга — снимок ScrapingDog, нет и его — Buy Box.
  Продаж меньше `plan_price_min_units` (3) — цена листинга, а не продаж.
- **Прошедшая скидка видна в более позднем снимке Listings Items**: Amazon хранит последнее расписание sale price
  (`start_at`/`end_at`). Для дат без снимка (до 15.10.2026) ноутбук берёт скидку из самого раннего снимка после даты,
  если её окно покрывает дату расчёта. Так 84515000 ES на 15.09 получил 129,99 € (скидка 03.09–30.09), а не 169,95 € из
  отчёта листингов. Более ранние скидки того же листинга так не восстановить — хранится только последнее расписание.
- **Цена витрины ScrapingDog — не обязательно наша.** 54287000 IT: в снимке 39,98 €, а у нас в Listings Items 75,95 €
  без скидки (B2B 49,95 €), Buy Box `no_offers` — на витрине висело чужое или прошлое предложение. Контроль
  «SP-API ↔ ScrapingDog» (`plan_price_scrape_diff_pct`, 15 %) печатает такие пары; 14.10 их 4 из 256.
- С 14.10.2026 у аналитика в таблице временное решение: вкладки `prices_*` (вставленная вручную цена листинга / оффера)
  и формула AVG Price = MAXIFS по ним. У Amazon она берёт цену ЛИСТИНГА (ES — FBM, IT/FR/DE — FBA), в том числе
  неактивного: у 49274000 IT там 18,98 € неактивного FBA-листинга при 37,98 € на живой витрине. Наши цены с этими
  вкладками не обязаны совпадать.
